동대문 주문취합

동대문 주문내역 파일 1개를 업로드하면 샘플, 품절, 입고일정 건을 자동으로 분류합니다.
일정 키워드별 실제 입고일을 입력하면 Q열 바코드 기준으로 셀메이트 입고예정일 입력 파일을 생성합니다. 화면은 빠른 확인을 위해 일부만 미리보기로 표시하고, 다운로드는 전체 반영됩니다.
기준 열: A 공급처 / D 사입명 / E 상품명 / F 옵션 / H 주문수 / J 입고수 / N 메모
제외 기준: 상품명에 샘플·반품 포함, 메모 품절/종료 건은 입고일정에서 제외
품절/종료 요청과 샘플 건을 바로 확인할 수 있도록 정리합니다.
예: 수밤 → 2026-06-18 / 목밤 → 2026-06-19 / 다음주중 → 2026-06-25
