포레스트핏 장기지연건 입고/납기 자동 비교

처음 사용하는 경우, 각 업로드 영역 아래의 첨부 파일 다운로드 방법을 순서대로 따라 파일을 다운로드한 뒤 첨부해 주세요.
기존 파일과 오늘 파일을 비교하여 입고예정일 변경 여부를 확인하고, 브리치 파일을 함께 업로드하면 비플로우 건의 출고준수일을 보정합니다.
첨부 파일 다운로드 방법

1. 셀메이트 접속
2. 주문관리 메뉴 클릭
3. 판매처분류에서 GS를 제외한 전 채널 선택
  - 네이버 / 롯데온 / 비플로우 / 와디즈 / 카카오톡스토어 / 퀸잇 / 하프클럽
4. 조회기간을 임의기간으로 설정
  - 시작일 : 3개월 전
  - 종료일 : 조회일 기준 평일 2일 전
5. 확장필터에서 출고불가 필터 적용
6. 조회 후 파일 다운로드
7. 다운로드한 파일을 이곳에 첨부
첨부 파일 다운로드 방법

1. 비플로우 접속
2. 판매관리 메뉴 클릭
3. 주문조회 클릭
4. 주문상태를 아래 2가지로 선택
  - 배송지연
  - 배송준비
5. 검색 버튼 클릭
6. 파일 다운로드
7. 다운로드한 파일을 이곳에 첨부
한 줄에 하나씩 입력하세요.
1/2 비교: D 주문번호 + G 상품명 + H 옵션 미매칭: 변경입고예정일 = 취소됨 or 출고됨 비플로우: 브리치 파일로 출고준수일 보정 N열: 출고불가 수식 자동 입력

결과 파일 다운로드 후 사용 방법

N열 출고불가는 엑셀 수식이 아니라 사이트에서 직접 계산해 입력됩니다.

J열 변경입고예정일과 M열 출고준수일이 같은 날짜이면 공백으로 처리되고, J열 날짜가 M열보다 늦은 경우에만 출고 불가로 표시됩니다.
