📌 2. 브리치 다운 파일 업로드

📎 첨부 파일 다운로드 방법

1. 비플로우 접속
2. 판매관리 메뉴 클릭
3. 주문조회 클릭
4. 주문상태를 아래 2가지로 선택
  - 배송지연
  - 배송준비

5. 조회기간
- 시작일 : 3개월 전
- 종료일 : 조회일 기준 평일 2~5일 전

6. 검색 버튼 클릭
7. 파일 다운로드
8. 다운로드한 파일을 이곳에 첨부

📌 3. 공휴일 입력
