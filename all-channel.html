📦 기프트허브 - 장기지연 납기관리

📌 사용 안내

이 시스템은 셀메이트 + 브리치 파일을 기반으로
전체 채널 장기지연 및 출고 리스크를 자동 계산합니다.

업로드 순서:
1. 셀메이트 파일 업로드
2. 브리치 파일 업로드 (선택)
3. 공휴일 입력
4. 계산 실행

출력 기준:
- 괄호 상품명만 추출
- 채널별 출고준수일 자동 계산
- 입고 / 출고 비교로 출고불가 판정

📌 1. 셀메이트 파일 업로드

EX) 장기지연건 파일 업로드


📌 2. 브리치 파일 업로드

EX) 비플로우 다운로드 파일


📌 3. 공휴일 입력

EX) 2026-08-17 (콤마 또는 줄바꿈)
주문일자 지연일 판매처 주문번호 공급처 사입상품 상품 옵션 입고 출고준수 불가 상태 처리
