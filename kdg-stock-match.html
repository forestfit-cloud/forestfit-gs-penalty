케이디지 재고장 매칭

케이디지 베이스 파일과 재고장 파일을 업로드하면, 재고장 파일의 D열 사입명과 F열 사이즈를 기준으로 G열에 재고 수량을 자동 입력합니다.
재고장 파일은 기존 색상·글씨체·병합·테두리 양식을 유지하고 G열 값만 변경합니다.
사용 시트: 여성복(사계), 남성복(사계), 여성복(여름), 남성복(여름)
기준: B열 품번 / D열 S / E열 M / F열 L / G열 XL / H열 2XL / I열 3XL
재고장 사입명이 7로 시작하면 여성복(사계) 시트만 조회 / 품번·기장 + 사이즈 열 기준
베이스 파일에 위 4개 시트 외 다른 탭이 있으면 삭제 후 첨부해주세요.
시트명이 다르면 해당 시트는 자동으로 제외됩니다.
기준: D열 사입명 / F열 사이즈 / G열에 재고 입력
D열 병합 셀은 위에 적힌 사입명으로 자동 인식합니다.
